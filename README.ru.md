# RolyPolyOps

[English](README.md)

Резервные копии, проверяемое восстановление сервисов и безопасное переключение между независимыми хостингами.

**Состояние: 0.1.0, ранняя версия управления тестовым пакетом PostgreSQL/Compose.
Двуязычная панель подключает серверы, проводит настройку, запускает зашифрованное копирование,
проверки восстановления, сохраняет отдельные пробные копии и управляет расписанием.
Поддержка произвольных приложений и автоматическое переключение пока отсутствуют.**

Начните с [руководства управления](control/README.ru.md). Отдельно версионируемый
[стенд восстановления](demo/README.ru.md) содержит испытанный пакет сервиса и механизм копирования.

## Назначение

- Зашифрованные копии по расписанию с историей и независимыми местами хранения.
- Восстановление сервиса целиком: базы, файлов, конфигурации и версии приложения.
- Пробное восстановление с проверкой изолированного приложения дополнительно к целостности архивов.
- Профили для одного сервера, основной и резервной площадок, нескольких независимых площадок.
- Явная политика потери данных и защита от двух одновременно записывающих основных баз.
- Документация продукта на английском и русском с одинаковыми разделами и идентификаторами контрактов.

## Профили

| Профиль | Предусмотренное поведение |
|---|---|
| Один сервер | Копии и восстановление на совместимый новый сервер |
| Пара с подтверждением | Подготовленный резерв, блокировка источника и подтвержденное переключение |
| Автоматическая пара | Дополнительный профиль с проверенным внешним отключением и полномочиями решения |
| Кластер | Управление ролью PostgreSQL через Patroni и большинство etcd |

Количество серверов само по себе не доказывает независимость площадок и не разрешает автоматику.
Реплики хранилища не заменяют историю резервных копий.
