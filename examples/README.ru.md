# Примеры манифестов сервиса

[English](README.md)

Манифесты описывают исходный контракт конфигурации. Они не выполняют операции на серверах.
Все примеры используют зарезервированные адреса .invalid и идентификаторы секретов вместо значений.
RPO/RTO являются примерными требованиями политики, а не измеренными гарантиями.

- [Один сервер](service-single.json)
- [Пара с подтверждением](service-pair.json)
- [Кластер](service-cluster.json)
- [Автоматическая пара с внешней политикой отключения](service-pair-automatic.json)

[схему](../schemas/service-package.schema.json).
