# Совместимость и текущее состояние

[English](../en/compatibility.md)

**Кандидат 0.2:** добавлен мастер своих сервисов Compose и хранилищ REST/S3. Границы поддержки, порядок работы и ограничения: [руководство](../../docs/ru/compose-services.md). Проверка на двух действующих серверах и решение о выпуске остаются отдельными условиями. Разделы про тестовое приложение ниже описывают сохраненный режим 0.1.

## 1 Доступные материалы

Сейчас доступны спецификация продукта на английском и русском, исходная JSON Schema профилей, иллюстративные манифесты и [исполняемые инструменты стенда](../../demo/README.ru.md) для тестового приложения PostgreSQL. Стенд сохраняет и восстанавливает только это приложение, работающее на чтение. [Начальная панель управления](../../control/README.ru.md) подключает серверы и управляет этим пакетом. Кандидат 0.2 добавляет подключение поддерживаемых обычных проектов Compose через мастер своих сервисов. Репликация, автоматическое изменение DNS и отключение хостера не реализованы.

## 2 Целевая среда

Базовая целевая среда: Linux, PostgreSQL и контейнерные сервисы с постоянными файлами. PostgreSQL, pgBackRest, restic, Patroni, etcd, HAProxy и дополнительные компоненты файлового хранения сохраняют поведение и лицензии исходных проектов. Проверенной матрицы точных версий пока нет.

Приложению нужен пакет согласованного копирования и восстановления. Другие базы, почта, виртуальные машины и Kubernetes являются отдельными профилями совместимости; их поддержка не следует из одного запуска контейнера.

## 3 Параметры конкретного размещения

Необходимы версии приложений, объем и скорость изменения данных, требования RPO/RTO, области отказа, права API хостера, устойчивое отключение, задержки сети, место, доступность образов и ключей восстановления.

Общая гарантия времени восстановления, коэффициент сжатия и неограниченная устойчивость к отказам не заявляются. Наблюдения на стенде относятся только к испытанным данным и среде. Схема проверяет только объявленные значения и не подтверждает эти свойства размещения.
