# Требования и ограничения

[English](../en/requirements.md)

## 1 Функциональные требования

| Код | Требование |
|---|---|
| FR-01 | Зашифрованные копии по расписанию и история |
| FR-02 | Независимые хранилища с отдельным состоянием передачи и целостности |
| FR-03 | Точка, связывающая базу, файлы, конфигурацию и версию приложения |
| FR-04 | Восстановление всего сервиса на выбранную совместимую цель |
| FR-05 | Пробные восстановления по расписанию в изоляции с полезными проверками |
| FR-06 | Политики одного сервера, пары с подтверждением, автоматической пары и кластера |
| FR-07 | Блокировка источника при переключении пары и безопасный возврат резерва |
| FR-08 | Полномочия кластера через Patroni и etcd |
| FR-09 | Явные переходы без молчаливого ослабления политики |
| FR-10 | Понятные состояние, планы, результаты операций и необходимые решения |

## 2 Требования безопасности и эксплуатации

SR-01: единственный разрешенный источник записи. SR-02: запрет молчаливого ослабления политики потери данных. SR-03: сервер приложения не может удалить всю историю. SR-04: секреты отсутствуют в исходниках, журналах и отчетах. SR-05: пробное восстановление не вызывает реальные внешние действия.

OR-01: восстановление без источника и управления. OR-02: прерванная операция наблюдаема и безопасно продолжается. OR-03: разрешенное местное копирование переживает потерю управления. OR-04: измеряются фактические потери и время восстановления.

## 3 Сценарии проверки

| Код | Сценарий |
|---|---|
| T01 | Восстановить базу и соответствующие версии вложений |
| T02 | Отклонить повреждение или пропущенный WAL |
| T03 | Восстановить после потери источника и управления |
| T04 | Разорвать связь пары без двух записывающих основных баз |
| T05 | Потерять каждую отдельную площадку кластера и проверить роли и данные |
| T06 | Повторить запрос, потерять ответ и перезапустить во время изменения |
| T07 | Восстановить историю после удаления или захвата источника |
| T08 | Проверить полезную функцию в изоляции без реальных внешних действий |
| T09 | Прервать переход профиля без опасного пересечения полномочий |
| T10 | Вернуть прежний основной сервер резервным |
| T11 | Потерять хранилище и показать очередь и риск заполнения |
| T12 | Восстановить старую версию приложения и пакета |

Эти сервисные сценарии не выполнялись. Проверка схемы не считается T01-T12.
