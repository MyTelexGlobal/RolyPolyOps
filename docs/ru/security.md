# Безопасность продукта

[English](../en/security.md)

## 1 Защищаемые данные и полномочия

Защищаются данные сервиса, история копий, ключи шифрования, доступ к хостеру, права DNS и полномочия основной базы. Приложение, служба сервера, привилегированный помощник, управление, хранилище и аккаунт владельца являются отдельными областями доверия.

## 2 Необходимая защита

| Угроза | Необходимая защита |
|---|---|
| Две записывающие основные базы | Единственные полномочия, блокировка источника и безопасный возврат |
| Повтор опасного действия | Ключ повторяемости, ревизия, срок действия и сверка факта |
| Захват сервера приложения | Отсутствие постоянного права удаления всей истории |
| Кража идентичности сервера | Отдельные сертификаты, отзыв и ограниченные команды |
| Подмена плана | Подтверждение связано с хешем и ревизией |
| Произвольное выполнение команд | Доверенные пакеты и ограниченные привилегированные действия |
| Реальные действия восстановленной копии | Изолированные ключи и ограничения исходящих соединений |

Секреты задаются отдельными ссылками, шифруются при хранении и исключаются из журналов и отчетов. Внешние соединения требуют проверки подлинности и шифрования.

## 3 Ограничения и сообщения

Это требования безопасности, а не утверждение о завершенной реализации или аудите. Полный захват административных полномочий остается серьезным остаточным риском. Отключение у хостера, защита истории и доверие к пакетам проверяются для каждого поддерживаемого размещения.

Чувствительные сведения передаются через приватный канал сообщения об уязвимости репозитория, если он доступен. Ключи, реальные архивы и клиентские данные нельзя включать в публичные задачи. Если приватного канала нет, запросите контакт без раскрытия чувствительных подробностей.
